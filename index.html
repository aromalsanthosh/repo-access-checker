Repo Access Checker

Paste a GitHub repository link and a token to see whether the token can reach the repo, what role it has, and which parts of the repo it can read.

Accepts URLs, owner/repo, or SSH remotes like git@github.com:owner/repo.git.

Your token is sent only to the GitHub API, straight from your browser. It is never stored or sent anywhere else.

Only read-only GET requests are made. Nothing in the repository is changed.
